# Project notes: Extract from Zombieville, Dead City Nights, the map builder, the Duvallville poster game

Read this first after a compaction. Three games in one Vite repo, deployed to GitHub Pages on push to main (~1 min):
- index.html = Extract from Zombieville (tap-to-route maze game). index.html?build=1 = in-world map builder. editor.html = 2D grid builder.
- deadcity.html = Dead City Nights (third-person joystick, six nights, missions, vehicles, spells). ?custom=1 plays the builder map, ?horde=100 spawns a horde.

## Blocky game rules (current)
- 10 districts; district 1 is the tutorial (15x23 on portrait); districts grow +2 cells per level (cap +12). Zoning: downtown north, mixed middle (landmarks), houses south. One straight avenue across and one down in every district.
- Gate puzzle from district 2: gate on the route, alternate routes sealed with buildings, yellow switch elsewhere opens it. Arrow steps gate -> switch -> exit; opening the gate sets a checkpoint.
- Exit chosen among far-by-road cells, preferring physically close ones. District 10: helipad + chopper evac finale (`finishGame`).
- Lives 3 (medkits to 5), one touch = lose a life (vest absorbs one). Start each district with pistol x6 (or rifle x20 with ammo crate).
- Score: 100/alive civilian, 250/follower at exit, 10/kill, speed bonus; streak multiplier up to x5 within 8 s. Cash: half of scored points on kills/recruits + payout on clear (60/rescued, 10/alive, 100).
- Store (district-cleared screen): ammo 60, medkit 120, vest 150, shoes 200 (x3, +10% speed each), flare 90 (sprint drops a lure), car keys 600, repair 150. Car: 1.7x speed, runs zombies down, 1 hp per hit, 5 hp, wreck at 0; carries over.
- AI: zombies shamble (0.45 speed) until alerted by sight (<9 units LOS), gunfire noise (<14), flare, or an alerted neighbour; then chase via flow field; prey civilians first (within 9, LOS). Civilians wander/chat, flee threats, run to the player for help when within 7, follow in a line once recruited (speed 1.1x player), chatter lines; speech bubbles over heads.
- Dynamic: lamp flicker, straggler zombies from edges (district 2+), searchlight sweep, ruins with fires/smoke outside the walls.
- Debug hook: `window.__oo` (player, zombies, civilians, pickups, exit, gate, switchCell, routeTo(cx,cy), toWorld, cash setter, driving, inv). Poster: `window.__dv`.

## Poster game (beta)
- Night painting from the artist's files. Source: `example sprites/illustrator/ISO/_Flat_tobe main_Flat.ai` is the FINAL layout (aligns with `_FINAL-NIGHT2.jpg`). Layers are PDF OCGs rendered by `tools/ai-layers.mjs` (pdf.js + @napi-rs/canvas; Node crashes on exit after writing, harmless).
- Pipeline (order matters): `node --max-old-space-size=8192 tools/relight-poster.mjs 2 5` (clean vector render without people/cars, relit with the JPG's blurred luminance + teal tint) -> `tools/cut-potato.mjs` (potato monster sprite + erase its spot) -> `tools/build-poster.mjs 2` (ground tiles, structure strips masked by vector alpha, walk grid from ROADS layer). Build deletes only ground_/struct_ files.
- Camera true isometric (30-degree lines => elevation 35.26°), PPU 50 px/unit. Structure strips are camera-facing quads anchored at their bottom pixel so depth sorting works; player has an x-ray silhouette (depthFunc GreaterDepth).
- Figures baked into building layers (gas station crowd, coaster riders, bus, people by houses) remain in the art; everything else was removed. Potato monster roams via findPath and costs a life on touch.
- The 3 GB `example sprites/illustrator/` folder and `tools/poster/` are gitignored. NEVER `git add -A` without them ignored (a 3 GB commit was purged once).

## Gotchas
- `git checkout <file>` rewrites with CRLF (autocrlf). Patch scripts must normalize `\r\n` -> `\n` before matching multi-line anchors.
- Never use `String.replace` with a replacement string containing `$'`/`$&`; use a function replacer `() => b`.
- Bash heredocs with backticks/`$` break in this shell; write patch scripts to the scratchpad with the Write tool and run them with node.
- Browser pane is hidden while the user is on Remote Control: ~1 fps, so long animations/timers look stalled; drive state via debug hooks and wait generously.
- Dev server (`preview_start` name `game`, port 5173) dies during heavy node renders; restart it.
- iOS: sound needs the ringer switch off silent; pinch is handled via touch events + gesture preventDefault.
